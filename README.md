# 🎬 Хроники Кудрово: Интерактивный AI-сериал в Telegram

Полностью автономный бот для генерации, публикации и ведения интерактивного сериала-фанфика в Telegram-канале с живым вовлечением аудитории через опросы и комментарии.

---

## 📌 О проекте

Бот реализует концепцию **живого процедурного сериала**:
1. **Сценарист (ИИ)** дважды в день генерирует новую серию, развивая сюжет строго с учётом предыдущих событий, побед в зрительских опросах и отобранных идей читателей.
2. **Читатели** в Telegram-канале голосуют в опросах в конце каждой серии, определяя ключевые развилки сюжета.
3. **Бот-комментатор** общается со зрителями в привязанном чате обсуждений, отвечает на вопросы о вселенной сериала и проводит автономный триаж сюжетных идей зрителей, отбирая годные повороты и отсеивая спам.
4. **Администратор** имеет полный контроль над процессом через команды управления, предпросмотра и модерации.

```
    │ (CodeCraft / Claude) │                                 │ (Viewer Suggestions) │
    └──────────┬───────────┘                                 └──────────┬───────────┘
               │                                                        │
               └────────────────────────────┬───────────────────────────┘
                                            ▼
                               ┌─────────────────────────┐
                               │   Continuity Engine     │
                               │   & SQLite Database     │
                               └─────────────────────────┘
```

- **Язык**: Python 3.10+
- **Telegram Framework**: `aiogram 3.17+`
- **База данных**: `SQLite` (с асинхронным драйвером `aiosqlite` и WAL-журналированием)
- **Планировщик**: `APScheduler 3.10+` (cron-режим с привязкой к часовому поясу)
- **Сценарист (Narrator Engine)**: `CodeCraft API` (Claude / DeepSeek) — генерация сценария, опроса, обновление тайн и статусов персонажей
- **Агент комментариев (Comment Agent)**: `Groq API` (`openai/gpt-oss-120b`) — фильтрация сообщений и отбор сюжетных предложений
- **Управление конфигурацией**: `Pydantic Settings` + `.env`
- **Тесты**: `pytest` + `pytest-asyncio`

## ⚡ Ключевые возможности

### 1. Движок непрерывности сюжета (Continuity Engine)
- **Контекст без склероза**: модель получает актуальный синопсис (`rolling_synopsis`), статусы персонажей (`character_statuses`), список открытых тайн (`active_mysteries`) и концовку предыдущей серии.
- **Учёт зрительского выбора**: результат предыдущего опроса закрывается и автоматически встраивается в завязку новой серии.
- **Синхронизация лора**: новые персонажи, появляющиеся в процессе генерации, автоматически дополняются в `data/lore_bible.json`.

### 2. Умный агент комментариев
- **Экономия токенов**: игнорирует перепалки пользователей друг с другом и пустые междометия («ахаха», «лол», смайлики). Реагирует только на прямые обращения к автору и сюжетные предложения.
- **Автономный отбор идей**:
  - `approved`: интересные сюжетные ходы, адекватные второстепенные персонажи, конфликты и интриги.
  - `rejected`: бессмысленный спам, шизофазия, пошлые шутки, попытки моментально убить главных героев или сломать сеттинг.
- **Приоритет в сценарии**: одобренные идеи зрителей попадают в базу и обязательно передаются сценаристу для органичного внедрения в ближайшие серии.

### 3. Надёжная доставка в Telegram
- **Умное разбиение сообщений**: при превышении лимита Telegram (4096 символов) текст серии разбивается по границам абзацев на аккуратные части `[1/2]`, `[2/2]`.
- **Отказоустойчивость**: повторные попытки (retry) через `tenacity` с экспоненциальной задержкой при сбоях сети или API.
- **Безопасная HTML-верстка**: экранирование тегов и автоматический plain-text fallback при ошибках парсинга Telegram.

## 🚀 Установка и запуск

### 1. Клонирование и окружение

```bash
git clone https://github.com/m43stro-original/storyteller.git
cd storyteller

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
# Telegram
TELEGRAM_BOT_TOKEN="1234567890:ABCDefGhIJKlmNoPQRstuVWXyz"
CHANNEL_ID="-1001234567890"          # ID канала для публикации серий
DISCUSSION_CHAT_ID="-1009876543210"  # ID группы комментариев
ADMIN_IDS="123456789,987654321"     # Telegram ID администраторов

# Narrator LLM (CodeCraft / OpenAI-compatible)
CODECRAFT_API_KEY="cc_your_api_key_here"
CODECRAFT_BASE_URL="https://codecraftapi.com/v1"
CODECRAFT_MODEL="claude-sonnet-5"    # или deepseek-v4-flash-0731

# Comment Agent LLM (Groq)
GROQ_API_KEY="gsk_your_groq_api_key_here"
GROQ_BASE_URL="https://api.groq.com/openai/v1"
GROQ_MODEL="openai/gpt-oss-120b"

# Расписание релизов (cron в Europe/Moscow, через точку с запятой)
SCHEDULE_CRON="10 12 * * *; 0 19 * * *"
TIMEZONE="Europe/Moscow"

# Пути
DB_PATH="data/kudrovo.db"
LORE_BIBLE_PATH="data/lore_bible.json"
STORY_PROMPT_PATH="prompts/story_prompt.txt"
```

### 3. Локальный запуск

```bash
python main.py
```

### 4. Запуск в фоне через systemd (Linux)

Создайте сервис `/etc/systemd/system/kudrovo-bot.service`:

```ini
[Unit]
Description=Kudrovo Telegram Serial Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/hist
ExecStart=/root/hist/.venv/bin/python /root/hist/main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Управление сервисом:
```bash
sudo systemctl daemon-reload
sudo systemctl enable kudrovo-bot.service
sudo systemctl start kudrovo-bot.service
sudo systemctl status kudrovo-bot.service
```

## 🛠 Команды администратора

Команды отправляются боту в личные сообщения администратором (из списка `ADMIN_IDS`):

| Команда | Описание |
|---|---|
| `/status` | Текущий номер серии, открытый опрос и состояние сюжета |
| `/preview` | Генерация черновика серии с отправкой в ЛС админу (без публикации в канал) |
| `/post_now` | Принудительный внеочередной выпуск следующей серии в канал |
| `/ideas` | Просмотр свежих сюжетных предложений читателей со статусами |
| `/approve <id>` | Вручную утвердить идею зрителя в наивысший приоритет |
| `/reject <id>` | Отклонить идею зрителя |
| `/lore` | Краткий вывод информации о мире и ключевых персонажах |
| `/help` | Список доступных команд |

## 🧪 Запуск тестов

Тестовый набор покрывает репозиторий, изоляцию баз данных, парсеры JSON, разбиение сообщений, генерацию промптов и алгоритм отбора идей.

```bash
pytest -v
```

Все тесты изолированы и используют временные базы данных в памяти / тестовые файлы, не затрагивая боевой `data/kudrovo.db`.
